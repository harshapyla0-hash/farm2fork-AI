Farm2Fork AI website prototype
================================

Run locally:
1. Extract this folder.
2. Open index.html in a modern browser (Chrome/Edge).
3. No install/build step is needed.

Features:
- Responsive website layout
- Command Center dashboard
- Surplus marketplace with working add/list flow and category filter
- Expiry-based heuristic risk alerts
- Demo rescue matching that updates inventory and rescue ledger
- Impact tracker with editable illustrative emissions factor and CSV export
- Demand/stock simulator
- English/Telugu navigation labels
- Reset demo data

Important limitations:
- All initial suppliers, partner organizations, inventory and demand figures are simulated.
- No live backend, user authentication, maps, routing, notifications, partner verification, or external data feeds.
- Confirming a match only changes in-browser demo state.
- Expiry risk is a heuristic, not food-safety certification.
- Emissions factor is a placeholder scenario assumption.
- Google Fonts and food imagery use external URLs and may require internet access. The core app logic works locally.
